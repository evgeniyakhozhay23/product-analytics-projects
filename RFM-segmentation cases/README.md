# RFM-сегментация студентов онлайн-школы

### Условие кейса и данные:

Karpov Courses, курс "Аналитика данных" (https://karpov.courses/analytics), модуль "Продуктовая аналитика и A/B тесты"

### Структура данных:
Работа ведется с 4 файлами:

1. assessments.csv — информация об оценках в тесте. Обычно каждый предмет в семестре включает ряд тестов с оценками, за которыми следует заключительный экзаменационный тест (экзамен).
- code_module — идентификационный код предмета.
- code_presentation — семестр (Идентификационный код).
- id_assessment — тест (Идентификационный номер ассессмента).
- assessment_type — тип теста. Существуют три типа оценивания: оценка преподавателя (TMA), компьютерная оценка (СМА), экзамен по курсу (Exam).
- date — информация об окончательной дате сдачи теста. Рассчитывается как количество дней с момента начала семестра. Дата начала семестра имеет номер 0 (ноль).
- weight — вес теста в % в оценке за курс. Обычно экзамены рассматриваются отдельно и имеют вес 100%. Сумма всех остальных оценок составляет 100%.
2. courses.csv - список предметов по семестрам
- code_module — предмет (идентификационный код).
- code_presentation — семестр (идентификационный код).
- module_presentation_length — продолжительность семестра в днях.
3. studentAssessment.csv — результаты тестов студентов (тех, кто отправил работу)
- id_assessment — тест (идентификационный номер).
- id_student — идентификационный номер студента.
- date_submitted — дата сдачи теста студентом, измеряемая как количество дней с начала семестра.
- is_banked — факт перезачета теста с прошлого семестра (иногда курсы перезачитывают студентам, вернувшимся из академического отпуска).
- score — оценка учащегося в этом тесте. Диапазон составляет от 0 до 100. Оценка ниже 40 неудачная/неуспешная сдача теста.
4. studentRegistration.csv — информациz о времени, когда студент зарегистрировался для прохождения курса в семестре
- code_module — предмет (идентификационный код).
- code_presentation — семестр (идентификационный код).
- id_student — идентификационный номер студента.
- date_registration — дата регистрации студента. Это количество дней, измеренное от начала семестра (например, отрицательное значение -30 означает, что студент зарегистрировался на прохождение курса за 30 дней до его начала)
- date_unregistration — дата отмены регистрации студента с предмета. У студентов, окончивших курс, это поле остается пустым.

### Цель проекта
Проанализировать поведение студентов на курсах, предметах и экзаменах онлайн-школы
### Содержание проекта
1. Кейс 1: успеваемость студентов

Данные из assessments.csv и studentAssessment.csv
   - оцениваю количество студентов, которые закрыли только 1 курс (разделяю те предметы, которые закрываются экзаменом, и совокупностью разных тестов по их весам в общей оценке)
   - оцениваю средний балл по предметам, разным видам тестирования в целом и по семестрам 
   - проверяю на наличие взаимосвязи между датой регистрации на курс и результатами тестов (визуализация с помощью диаграммы рассеивания)
   - проверяю на наличие взаимосвязи между датой регистрации на курс и временем, которое уходит на выполнение тестов (визуализация с помощью диаграммы рассеивания)
   - выявляю количество студентов, не прошедших тестирование, и перечень тех, кто пропустил больше одного теста (с информацией о предмете)
2. Кейс 2: уровень завершаемости экзаменов
   - рассчитываю кол-во успешных завершений экзамена по каждому тесту (id_assessment)
   - рассчитываю кол-во всех сдач экзамена по каждому тесту
   - доли успешных завершений сортирую по возрастанию и смотрю, к какому предмету относится экзамен
3. Кейс 3: популярность предметов по количеству регистраций

Добавление данных из таблицы studentRegistration.csv

4. Кейс 4: предметы по количеству отменивших регистрацию студентов (отток студентов)
5. Кейс 5: уровень завершаемости экзаменов в группировке по семестрам
6. Кейс 6: средние сроки сдачи курсов по семестрам
- оцениваю время, которое в среднем отводится на выполнение тестов по семестрам
- рассчитываю время, которое в среднем тратят студенты на выполнение тестов по семестрам
- оцениваю время, которое в среднем тратят студенты на выполнение экзаменов
- выявляю топ-5 тестов (по id_assessment) по длительности выполнения студентами в каждом семестре
7. Кейс 7: RFM-кластеры студентов и оценка аудитории онлайн-школы
- R — среднее время сдачи одного экзамена
- F — завершаемость курсов
- M — среднее количество баллов, получаемое за экзамен

Провожу интерпретацию кластеров, смотрю содержание по количеству студентов в каждом из сегментов. 

**Вывод:** 
- Основная масса наших студентов - это те, кто закрывают экзамены со средними баллами, тем не менее успешно
- Больше тех, кто завершает экзамен в более короткий срок, но большое количество и таких студентов, кому нужно больше времени на работу.
